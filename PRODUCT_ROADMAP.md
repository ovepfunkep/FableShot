# FableShot — что сделано и что впереди

Обновлено **10 ноября 2026 · версия 0.30.1 (59)**. Основная и жёлтая тестовая копии обновлены до одной версии.

Три части плана: **выполнено → предстоит → отложено**. Здесь перечислены возможности приложения; текущая задача, проверки и состояние телефона — в [рабочей очереди](docs/work-queue.md). Сроки и общий процент готовности пока не назначены.

## 1. Выполнено

Это уже работающие возможности. Оставшиеся расширения каждого направления находятся во второй части.

- [x] Темы Спорт, Поп и Минимал; светлое и тёмное оформление. Спорт включён по умолчанию.
- [x] Главная, История, Прогресс, Снаряжение и профиль; общие компоненты, иконки и геометрические фоны.
- [x] Онбординг, учебный пример и повторный доступ к обучению из настроек.
- [x] Пояснения во всплывающих окнах: подчёркнутые термины и значки рядом с заголовками.

- [x] Учёт диаметра древка при касании границы зоны. Координата центра хранится отдельно от засчитанных очков.
- [x] Промахи и поддерживаемые зоны учитываются по правилам мишени. Невнесённые стрелы не превращаются в промахи.
- [x] Структура «Тренировка → Раунд → Серия → Попадание».
- [x] Быстрый запуск привычной тренировки, изменение условий и избранные варианты с именами и поиском.
- [x] Ограничение раунда стрелами, сериями или свободный режим. Новый старт — 30 стрел в раунде; два таких раунда дают 60. Старые планы сохраняются.
- [x] Серии можно закончить раньше или ввести больше стрел. Переходы «Следующая серия / Следующий раунд / Завершить тренировку» учитывают план.
- [x] Досрочное начало нового раунда, смена условий, пауза, продолжение и повтор сохранённой тренировки.
- [x] Очки и средние серии/раунда; максимум серии и раунда считается по числу внесённых зачётных стрел.
- [x] Правка обычных и номерных попаданий в текущих/прошлых сериях и завершённых тренировках; отмена правок и сохранение при выборе другой стрелы.
- [x] Удаление попадания, серии или раунда с подтверждением. Пустая последняя серия удаляется при завершении.
- [x] Общая закреплённая панель активной тренировки и редактора серии; выбранная стрела выделена на мишени и в списке.
- [x] Цветные попадания: до шести без прокрутки, длинная серия — горизонтальная лента с обозначением доступного направления.
- [x] Плавные обновления чисел и последовательный показ выбора номера стрелы; тяжёлый пересчёт сводок вынесен из потока интерфейса.
- [x] Счётчик стрел без оценки — отдельный режим тренировки.

### Мишени, снаряжение и номерные стрелы

- [x] Поддерживаемые одноцентровые мишени: учебная, полная наружная, indoor с обычной/малой десяткой, уменьшенная 80 см.

- [x] Каталог луков, стрел и комплектов: добавление, редактирование, избранное и архив.
- [x] Снимок условий и снаряжения в тренировке: правка или архивация предмета не переписывают прошлые результаты.
- [x] Номерные наборы стрел; включение нумерации на тренировку, выбор номера кнопками и защита от повторного номера в серии.
- [x] Анализ отдельных физических стрел: попадания на общей мишени, центры и круги кучности, поиск стрелы, выбивающейся из группы.

### Главная и история

- [x] Общие счётчики всей истории и компактная шкала недавних тренировок на главной.
- [x] Новые тренировки сверху; даты в кругах на вертикальной шкале с границами месяцев и лет.
- [x] Поиск, отбор по датам и условиям. Карточки показывают результат, средний, доступный прогресс и разрядный уровень.

- [x] Корзина внутри фильтров истории: полные карточки удалённых тренировок с розовым фоном и восстановлением.

### Статистика тренировки и общий прогресс

- [x] Отдельная статистика каждой тренировки: условия сверху, итоги раундов и компактные серии со всеми цветными попаданиями.
- [x] Классические очки; Общие очки с надбавками за кучность и стабильность; Прогрессивные — сравнение с заранее сохранённой базой похожих тренировок.
- [x] Разбор составляющих Общих очков; неполные серии не блокируют расчёт остальных полных серий.
- [x] Средний балл, кучность RMS, смещение, распределение зон, доля десяток и доступная динамика показателей.
- [x] Карта попаданий и плотности; выбор конкретной серии. Плотность по умолчанию, полупрозрачные ячейки с градацией частоты.
- [x] График среднего балла по ходу тренировки с границами раундов и значениями выбранных точек.
- [x] Общая динамика по всем тренировкам: видимое окно около месяца, прокрутка к ранним данным и выбор показателя.
- [x] Выбор периода, своих дат, произвольного набора тренировок и сопоставимых условий для общей аналитики.
- [x] Прогресс в процентах относительно обычного среднего; исходный/текущий средний и пояснение по нажатию. При нулевой базе — прибавка в баллах.
- [x] Явная область расчёта: разные условия не смешиваются молча, неподтверждённые данные не выдаются за точные.
- [x] Настройки видимости отдельных показателей и графиков.

### Нормативы и разряды

- [x] Офлайн-справочник поддерживаемых числовых нормативов по типу лука, категории и формату упражнения.
- [x] Раздельный прогноз уровня серии и раунда в правом углу их плиток, рядом с очками и средним.
- [x] Уровень каждого раунда в статистике и сопоставимый общий уровень в истории.

Прогноз по тренировке не присваивает официальный разряд. Для неизвестных условий норматив не выдумывается. [Спецификация](docs/sport-ranks.md).

## 2. Предстоит

Это оставшаяся работа в принятом плане. Порядок ниже — направления развития, а не обещание сроков. Конкретный следующий пакет выбирается в [очереди](docs/work-queue.md).

### Мишени и нормативы

- [ ] Расширять проверенные форматы мишеней и нормативов, сохраняя старые результаты без пересчёта по новым правилам.

### Более глубокий разбор и отчёты

- [ ] Расширить выводы «что улучшилось и относительно чего» по доступным показателям.
- [ ] Доработать подборки «Мой прогресс», «Начало и конец», «Снаряжение», «Обзор сезона» и разбор частей занятия.

### Достижения, рекорды и турниры

- [ ] Оставшиеся применимые идеи [основного каталога достижений](docs/brainstorm/11-achievements-and-rarities.md) по мере готовности зависимых функций; калибровка условий и редкостей по лукам и форматам.
- [ ] Расширить рекорды остальных полных форматов.
- [ ] Довести выбранные событийные эффекты и их оформление по общему стилю приложения. Все анимации приложения пока не объявлены завершёнными.

### Повседневные инструменты и защита данных

- [ ] Необязательные локальные напоминания о занятиях и резервировании, удобное управление копиями.
- [ ] Доработать таймер: гарантированный сигнал при блокировке и восстановление незавершённого отсчёта после завершения процесса. Сейчас эти гарантии отсутствуют.
- [ ] Расширять проверку на реальных выгрузках MyTargets и подтверждать сопоставление геометрии по известным попаданиям; неизвестные форматы не считать поддержанными автоматически.
- [ ] Расширять полный архив вместе с новыми функциями, прежде всего групповыми данными, с проверками переноса.

### Ранняя проверка групповой связи — R1

- [ ] Создать локальную комнату через точку доступа и подключить 2–3 настоящих Android.
- [ ] Проверить обмен, потерю связи, повторное подключение и сворачивание приложения.
- [ ] Измерить расход батареи и реальную вместимость точки доступа, постепенно увеличивая группу.
- [ ] При необходимости сравнить роутер и бесплатный интернет-вариант. Обязательной абонплаты не планируется; платные варианты — только запасные по отдельному решению.

**Цель — до 50 участников.** Вместимость одной точки доступа ещё не подтверждена; испытания нельзя заменить числом в настройках.

### Полноценная клубная комната

- [ ] Создание комнаты, приглашение/QR, список участников и итог встречи.
- [ ] Равные права: создатель не управляет чужими сериями. Каждый стреляет в своём темпе, со своим луком и числом стрел.
- [ ] Классический, Общий и Прогрессивный зачёты со своим местом в каждом; общий список и категории луков.
- [ ] По умолчанию — срез на моей серии: очки за неё и сумма до неё. Будущие серии быстрых участников в этот срез не попадают.
- [ ] Карточки участников, компактный список при большом числе игроков и ручное переключение вида.
- [ ] Участник остаётся в результатах после выхода, если опубликовал хотя бы одну серию.
- [ ] История комнаты на каждом телефоне. Удаление у себя не удаляет данные остальных.
- [ ] Ввод без связи и синхронизация после возвращения без дублей и чужих правок.
- [ ] Итоговый клубный отчёт и проверка на возрастающей группе.

### Дизайн, общая приёмка и выпуск

- [ ] Совместный проход с дизайнером: композиция, типографика, графики, состояния и движение.
- [ ] Полная цепочка: первый запуск → тренировка → статистика → архив → другой телефон.
- [ ] Проверка разных Android и физических размеров экранов, доступности основных действий в стандартном масштабе. Экстремальное системное увеличение исключено из доработок по твоему решению.
- [ ] Испытания большой истории, тяжёлых отчётов и комнаты: скорость, батарея и устойчивость.
- [ ] Проверка разрешений, защиты данных, обновления и восстановления.
- [ ] Тестирование семьёй и клубом, устранение блокирующих дефектов.
- [ ] Подписанный APK для распространения, понятная инструкция и список изменений. Публикация в магазине — отдельное решение.

## 3. Отложено

Эти возможности сохранены, но не входят в ближайшие обязательные пакеты. Возвращаем их в работу отдельным решением.

### Фотографии тренировок

- [ ] Фото из камеры/галереи и привязка к тренировке.
- [ ] Ручные отметки на фото, настройка масштаба/положения мишени и связь с уже внесёнными стрелами без дублей.
- [ ] Хранение фотографий вместе с дневником и перенос в архиве.

### Эдиты и автоматическое распознавание

- [ ] Эффектные эдиты при рекордах: чем значительнее достижение, тем ярче представление.
- [ ] Автоматическое определение попаданий по фотографии с помощью нейросети; сначала исследование точности и удобства подтверждения.

### Другие расширения

- [ ] Импорт из приложений помимо MyTargets.
- [ ] Видеоанализ техники, часы и датчики.
- [ ] Сложные полевые/3D-профили и полноценные турнирные сетки.

### Исключено из разработки

По решению 10 ноября эти задачи убраны из плана, а не перенесены на потом:

- Составные планы с разными условиями.
- Дальнейшая доводка черновиков тренировок и внесения занятий задним числом.
- Многоточечные мишени.
- Текст заметок в статистических PDF/CSV.
- Связь отчётов с будущими целями и турнирами.
- Цели по объёму, результату и технике.
- Расширенный редактор профиля и аватара.

Ранее исключены разминка как отдельный функционал, отдельный ввод попаданий числами, сравнение двух периодов, отдельная история прицела/обслуживания снаряжения, XP/игровые уровни и штрафы. Уже работающие возможности и старые данные сохраняются. Исключённые задачи не возвращаются автоматически.
