# FableShot Web 0.25.0

Один React-интерфейс для браузера и тестового APK через Capacitor. Есть гибкие серии, выбор раундов, правка попаданий, лупа/зум, удаление, завершение с компактным отчётом и продолжение. С 0.7.0 стартовый экран — Главная с четырьмя вкладками и локальным дневником нескольких тренировок.

GitHub Actions собирает и публикует PWA из этой папки на [GitHub Pages](https://ovepfunkep.github.io/FableShot/). Первый запуск требует сети. После подготовки офлайн-кэша приложение открывается без подключения. Дневник сайта хранится в браузере. Для переноса между APK и PWA используй архив.

На Xiaomi установлена React-копия **0.24.3 (27)**, `app.fableshot.android.webpilot`. После обновления сверены профиль и хеш дневника. На 0.24.1 проверены Главная, настройки, отчёт, редактор, сохранение PDF и CSV в Downloads. Подробности — в [рабочей очереди](../docs/work-queue.md).

На этой установке также проверены номерные стрелы, промахи, изменение предыдущего попадания с автосохранением, завершение, PNG и системное окно отправки. Удержание экрана подтверждено Android, показ тренировки при блокировке и защищённый выход — вручную пользователем. В React-копии оставлены демо-комплект и отдельная проверочная тренировка; прежняя практика не изменилась.

В 0.3.0 перенесён экран условий. Дистанция и диаметр используют одинаковые поля с быстрыми значениями. Доступны семь одноточечных мишеней Android, выбор комплекта, отдельное создание и редактирование лука/стрел и их диаметра. Раунд ограничивается стрелами, сериями или остаётся свободным. Формат выбирается до первого попадания. При смене условий непустая серия сохраняет свой снимок, новая получает новые условия. Есть избранные наборы с поиском и подтверждением удаления. Основные поля снаряжения реализованы. Остальные параметры каталога, номерные стрелы и режим без оценки относятся к следующим пакетам переноса.

Нужны Node.js 24, npm и Chrome для браузерных проверок. Из `web/`:

```powershell
npm ci
npm run dev
npm test

```

Сборка находится в `web/dist/`. Для локальной проверки подпапки GitHub Pages запустить `npm run preview -- --base /FableShot/`. Офлайн-кэш проверяется на этой сборке. Первый запуск на iPhone требует HTTPS и подключения к сети.

В текущем Windows-окружении вместо глобального `npm` можно из корня запустить `node .tools/web-npm/package/bin/npm-cli.js --prefix web run dev`.

Он генерирует оболочку во вспомогательном каталоге и проверяет соответствие вложенных файлов `dist/`. Результат — `artifacts/FableShot-Web-pilot.apk`, пакет `app.fableshot.android.webpilot`. ## Результат проверки

В 0.12.0 отчёт показывает прогресс PG1 относительно сохранённой базы. База строится при старте или смене условий, использует до пяти похожих завершённых занятий с 12 стрелами в каждом и становится готовой от трёх. При нулевом исходном среднем изменение показано в баллах. Исправление или удаление источника отмечается отдельно, исходные суммы снимка сохраняются.

В 0.13.0 добавлены общий норматив упражнения по нескольким совместимым раундам, шкала и разбор, а также настройки видимости 15 уже перенесённых показателей. Отключение меняет представление, не исходные результаты или расчёт CG3. Выбор хранится отдельно от дневника; прежние настройки совместимы, по умолчанию всё включено.

В 0.14.0 экспортируются PNG с предпросмотром/скачиванием/отправкой, A4 PDF с карточкой и статистикой и UTF-8 BOM CSV. CSV использует поля Android `fableshot-shots-v1`, дополнительно `round_number`/`series_number`; координаты переводятся в Y-up, неизвестные факты не подставляются. В PNG каждая стрела входит ровно один раз, большие серии и раунды переносятся на следующие части. Web Share зависит от браузера; ссылки на скачивание доступны всегда. В исходниках native bridge добавлены PNG/CSV и отправка через Android, их проверка на устройстве впереди.

### Предыдущий пакет памяток 0.5.0

В 0.5.0 перенесены каталог и редактор памяток из Kotlin: компактный список, отдельные детали пунктов, автосохранение, версии, основная/архив/дублирование, краткий режим и фокусы, JSON/TXT импорт/экспорт. Чтение и TXT используют иерархию 1.1.1. Запись библиотеки проверяет конфликты; повреждённые данные не перезаписываются, несохранённый текст остаётся в редакторе при ошибке. В тренировку привязывается копия версии/фокусов с позицией серии и стрелы; редактирование библиотеки не меняет старый снимок и не создаёт серии. Завершённая тренировка читает свой снимок без повторного применения.

Настройки тренировки: скрывать очки вместе с подписями (статистика остаётся доступной), среднее до сотых, анимации, вибрация и удержание экрана. Вибрация по умолчанию выключена, как в Android. Настройки действуют на таймер, плитки и списки серий. Удержание экрана использует Screen Wake Lock на странице активной тренировки; не заменяет будущую нативную интеграцию с экраном блокировки.

**65 тестов логики/хранения, 22 браузерных сценария, production-сборка и APK прошли.** Xiaomi обновлён до 0.5.0 (5); просмотрены окна памяток и настроек, Screen Wake Lock разрешён телефоном. Отпечатки восьми локальных записей до/после обновления и просмотра совпали. Браузерный путь с искусственной памяткой: создание → подробности → автосохранение → публикация → фокус → отчёт → повторное открытие → защита завершённой тренировки.

### Предыдущий пакет таймера 0.4.0

В 0.4.0 добавлен таймер по Kotlin-компоненту. Доступен над стрелами и в параметрах условий. Перенесены запуск, пауза/продолжение, сброс/повтор, выбор серии/отдыха с подтверждением, длительности 120/60 и диапазон 1–3600. Обновляется только изменившаяся цифра MM:SS. Длительности сохраняются, текущий отсчёт живёт до завершения тренировки или процесса. Для учёта сна браузера используется абсолютное время окончания. После возвращения виден актуальный остаток, автоматического переключения серии нет.

**48 тестов логики и хранения и 18 браузерных сценариев** прошли. Таймер проверен с управляемыми часами, закрытием окна, паузой, сохранением настроек, ошибками записи и стабильностью ячеек цифр. APK 0.4.0 (4) установлен на Xiaomi, окно таймера открыто, шесть локальных записей до/после установки совпали. Физическая блокировка с отсчётом и Safari ещё требуют проверки.
