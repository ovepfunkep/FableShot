# Решённые вопросы

Закрытые обсуждения и их материалы хранятся здесь, чтобы не загромождать активный список. Последние решения также отражены в основных спецификациях.

- [Техническая основа](platform/README.md): Android APK, Kotlin + Compose; веб-демо сохраняется как референс.
- [Название и иконка](branding/README.md): FableShot, FS4 — лаймовая мишень со стрелой-пером.
- [Профиль](profile/README.md): P1, вход через аватар шапки, четыре нижних раздела.
- [Турниры](tournaments/README.md): T1 + TY1, анимации по личным настройкам.
- [Анимации](animations/README.md): AM1 + A1; AE01–AE05 и AE07–AE10. AE06 исключён.
- [Масштаб, бюджет и первый транспорт](group-requirements/README.md): до 50 стрелков, одна комната, без обязательной абонплаты; начать с точки доступа.
- [Прогресс](progress/README.md): PG1 для зачёта, PG2 в подробностях; база до 5 похожих занятий, минимум 3 по 12 стрел.
- [Общие очки](general-scoring/README.md): CG3, до 5% общего бонуса, кучность и стабильность; остальные показатели в аналитике.
- [Лидерборд](leaderboard/README.md): LB2 по умолчанию, LB1 от 9 участников в Авто, LB3 для истории.
- [Темп, срезы и история комнаты](group-rhythm/README.md): равные права, независимые серии, срез на моей, сохранение вышедших и локальная история.

Исторические альтернативы внутри подборок не являются выбранными задачами. Длительности эффектов, макеты, вместимость сети и другие инженерные детали ещё требуют разработки/испытаний.
