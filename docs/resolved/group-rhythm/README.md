# Темп комнаты и история — принято

Последнее решение пользователя заменяет прежнюю идею ожидания всех:

- Создатель задаёт комнату; затем права стрелков равны, центрального пульта нет.
- Каждый независимо заканчивает свои серии и переходит дальше. Разное число стрел допустимо. Никакой участник не блокирует остальных.
- После хотя бы одной завершённой опубликованной серии участник остаётся в лидерборде на весь срок жизни комнаты, даже после выхода. Полная серия из M тоже считается участием.
- Лидерборд по умолчанию показывает срез на моей серии. Если я на третьей, а другой на пятой, его четвёртая/пятая не входят в показанные результаты.
- Срез можно переключить вручную. Для него видны очки за серию и итог до неё. Отстающим показываются недостающие данные, а не выдуманные нули.
- Комната сохраняется в истории на каждом телефоне. Удаление своей истории не удаляет чужие записи и вклад участника в общую комнату.

Локально сохраняется последний полученный снимок: телефон без связи не может знать будущие чужие результаты. Срок серверного хранения ещё предстоит определить; он не ограничивает уже сохранённую локальную историю.
