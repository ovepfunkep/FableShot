# FableShot — название и иконка

Статус: выбрано пользователем 29 октября 2026. Эта страница фиксирует итог; файлы ниже сохраняют историю вариантов.

## Название

**FableShot** — точное написание с заглавными F и S, без пробела. Составное английское имя: fable + shot. Начальный язык интерфейса остаётся русским; бренд не переводится. Поясняющая подпись «Дневник лучника» допустима, её окончательное оформление ещё не выбрано.

Название используется в спецификациях и будущем интерфейсе. Имя Android-пакета и выпускные ресурсы будут закреплены при создании проекта; они ещё не создавались.

## Иконка

Актуальная версия — **FS4: мишень со стрелой-пером**, доработанная из первоначально выбранной I1 под название FableShot. Графитовая основа, лаймовые мишень/оперение и белое древко. Знак один для трёх внутренних оформлений приложения.

- [Отдельное мастер-изображение FS4](fableshot-icon-fs4-master.png).
- [Решение, сравнительный лист и требования к ресурсам](08-icon-refinement.md).

I1 сохраняется как исходное направление. Следующая задача — Android-слои и проверка масштаба/масок; выбор FS4 уже завершён.
