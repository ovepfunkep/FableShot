# Масштаб, бюджет и первый транспорт — принято

Подтверждено пользователем 29 октября 2026:

- До **50 стрелков** в одной клубной комнате одновременно.
- Без обязательной абонплаты; платное размещение только как резерв.
- Общей готовой Wi-Fi-сети может не быть; у участников доступен мобильный интернет.
- **Последнее решение: сначала попробовать через точку доступа телефона.** Создаём локальную Wi-Fi-сеть на месте; мобильный интернет/облако остаётся резервом.

Цель 50 сохраняется, но её нельзя считать подтверждённой вместимостью одной точки доступа. Проверить 2–3 телефона, затем 5/10 и увеличение до реального предела. Сетевой телефон обслуживает обмен и не получает дополнительных спортивных прав.

Ранее рекомендованный первый облачный Firebase Spark теперь запасной интернет-кандидат, Supabase Free — другая альтернатива. Ни облачный, ни локальный прототип пока не испытаны. Нельзя требовать подписку ради первого варианта.
