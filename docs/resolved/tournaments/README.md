# Турниры — выбраны T1 и TY1

**T1:** паспорт турнира, собственные старты/категории, связанные тренировки, ручной результат по протоколу и место. Можно отметить участие без подробных стрел. Несколько связанных тренировок не превращаются в несколько турниров.

**TY1:** золотая полоса слева, небольшая плашка и подпись «Турнир». Цвет мишени не меняется.

**Анимации соответствуют личным настройкам.** Турнирная отметка не включает тихий режим автоматически. Результат официального протокола хранится отдельно от рассчитанного по стрелам и товарищеских Общих/Прогрессивных очков.
