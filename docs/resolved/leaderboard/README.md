# Лидерборд — карточки LB2 по умолчанию

Решение пользователя: всё предложенное поведение сохраняется, **LB2 — основной вид; LB1 — когда игроков много**. LB3 остаётся дополнительной сеткой серий в истории.

## Выбор вида

Настройка **Авто / Карточки / Список**. По умолчанию «Авто»:

- До **8 участников включительно** — LB2, карточки.
- От **9 участников** — LB1, компактные строки.

Порог 8 выбран проектированием как начальное значение, пользователь отдельно число не называл. Считаются все стрелковые записи текущей комнаты, включая отставших/вышедших, которые ещё отображаются; табло/наблюдатели не считаются игроками. Фильтр категории не заставляет компоновку постоянно меняться. Вручную можно выбрать любой вид независимо от размера; это личная настройка, на чужие телефоны не влияет.

При открытии комнаты Авто сразу выбирает нужный вид. Если порог пересечён во время просмотра, Авто переключает вид, когда нет активного нажатия/прокрутки/раскрытого разбора, с сохранением видимого участника как якоря и короткой подписью причины. Во время взаимодействия переход откладывается; доступна подсказка «Участников стало больше · Перейти к списку». Не менять расположение под пальцем. Ручной выбор сохраняется, автоматический переход его не отменяет.

## Карточка LB2

Вверху место, имя, явный тип лука/категория и собственный маркер «Вы». Далее выбранная система и два крупных подписанных результата: **«За серию №k» / «Итог до №k»**. Ниже количество стрел, достигнутая серия, состояние связи и возраст данных при необходимости.

Мини-график показывает только доступные результаты **не позднее выбранной k**. Если участник на пятой, а срез на третьей, график тоже не раскрывает четвёртую/пятую. Общее «Завершено 5 серий» остаётся отдельным статусом. Нажатие раскрывает компоненты CG3, базу PG1 и другие места в текущей комнате.

Для ещё не завершённой k нет выдуманного нуля/полного места. Допустима вторичная подпись «42 после 2 серий», явно вне полного итога до третьей. Предварительная фаза CG3/PG1 и нехватка координат/базы имеют конкретную подпись.

Карточки читаемы при крупном шрифте, без обязательного сложного жеста. Собственный результат доступен через закреплённую компактную сводку, когда карточка ушла за экран.

## Общие элементы всех видов

Название комнаты/состояние связи; Классические / Общие / Прогрессивные; срез «Моя серия k» со стрелками/выбором номера; фильтры категории/совместимых условий; настройка вида. Ранги по умолчанию — по накопленному результату выбранной системы до k; переключатель «Места за серию» явно меняет основание. Оба значения остаются видимы.

Срез «Моя» привязан к последней начатой/завершённой серии; автоматически подготовленная пустая следующая ещё не двигает его. Ручной выбор отключает привязку, «К моей» восстанавливает. Будущие очки/компоненты не влияют ни на один вид.

Новые результаты не переставляют строку/карточку под пальцем во время взаимодействия или прокрутки. Показать «Есть обновления», применить перестановку по нажатию/возврату наверх. При неподвижном просмотре без активного жеста разрешена короткая анимация по личным настройкам, со стабильными ID и сохранением позиции. Без движения обновление мгновенное.

LB1 хранит те же поля в компактной форме. LB3 даёт горизонтальный разбор серий с закреплёнными именами, выбором среза и явными пропусками; он открывается дополнительно из истории/разбора комнаты. Виды меняют подачу, не формулы, данные и право участника остаться в истории.
