# Профиль — выбран P1

Аватар в шапке Главной открывает личный профиль. Четыре нижних раздела сохраняются. Локальный профиль не требует регистрации; подключение к комнате не публикует весь дневник.

Профиль показывает важную статистику, личный прогресс в выбранных условиях, рекорды, все достижения через галерею и турнирную историю. Подробные графики открываются в аналитике. Предлагаемые полки можно скрывать; отключение достижений не отключает обычные показатели прогресса.

[История вариантов и предложенное содержимое](03-profile.md). Точная компоновка полок ещё уточняется, место входа повторно не выбирается.
