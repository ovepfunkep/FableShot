# Техническая основа — выбраны Android и Kotlin + Compose

Пользователь подтвердил 29 октября 2026: **«Да, делаем»** в ответ на выбор Android-приложения на Kotlin + Compose.

Основная поставка — APK. Интерфейс Compose, локальное структурированное хранение Room, отдельный вычислитель спортивных метрик и транспорт комнаты. Настройки могут использовать DataStore по мере реализации. Сначала проверяется реальный вертикальный сценарий, а не вся широкая концепция одновременно.

PWA, Capacitor и Flutter сохранены в [истории сравнения](15-platform-pwa-or-android.md); выбор не открывается повторно без нового пожелания пользователя. Веб-демо остаётся референсом дизайна и не изменяется. Полная веб-версия не входит в текущую реализацию автоматически.

Текущая подготовка: реальный Xiaomi уже доступен через беспроводной ADB. Готовятся воспроизводимая сборка и первая установка debug APK; их результат фиксируется отдельно в [рабочем процессе](../../android-development-workflow.md).
