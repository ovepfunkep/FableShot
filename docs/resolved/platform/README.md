# Техническая основа — выбраны Android и Kotlin + Compose

29 октября 2026 года Иван подтвердил Android-приложение на Kotlin и Jetpack Compose. Поставка Android — APK, дневник хранится в Room.

11 ноября Иван исключил App Store. Для поддержки iPhone предложен [прототип PWA через Safari](../../architecture/iphone-pwa.md) с проверкой ввода и офлайн-сохранения на реальном телефоне. Решение о переносе Android на другой стек не принято.

[Первоначальное сравнение](15-platform-pwa-or-android.md) хранит обоснование выбора Android. Фактическое состояние сборок и проверок — в [рабочей очереди](../../work-queue.md).
