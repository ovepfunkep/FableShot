# Разрядный прогноз — варианты интерфейса

2 ноября 2026. Прогноз во время тренировки и отдельный блок нормативов в автоматически открываемой итоговой статистике согласованы пользователем. Конкретная компоновка ниже — предложение для обсуждения, приложение пока не менялось.

## Решение пользователя — заменяет варианты ниже

Без выбора нормативного упражнения перед стартом и без целей. В тренировке «По темпу: II», рядом допустим нормативный средний следующего уровня. Средний, необходимый на оставшихся стрелах, только по нажатию. После завершения сразу статистика с блоком нормативов: шкала среднего 0–10, риски разрядов и отдельный указатель текущего среднего. Профиль разделяет присвоенный разряд и лучший тренировочный результат.

Плавные обновления распространяются на всё приложение: [общий стандарт](../design/value-updates.md). Вопрос о постоянно видимом среднем решён. В первом пакете прогноз начинается с первой введённой стрелы. Отдельной кнопки «Нормативы» в тренировке нет; нажимается «По темпу».
