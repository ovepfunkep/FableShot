# Восстановление дневника после потери телефона

Текущий локальный архив помогает перенести дневник вручную. Для отказа или потери устройства нужна копия за его пределами и способ восстановить её без старого телефона. GitHub Pages раздаёт файлы приложения. Хранилище копий в него не входит.

- **Личное облако.** Пользователь один раз подключает место хранения. Приложение сохраняет проверяемые зашифрованные версии существующего архива. Права доступа ограничиваются папкой приложения. Этот вариант стоит проверить первым.
- **Системное резервирование.** Может дополнить APK, если сохраняет данные при переустановке и переносе. Текущая Android-оболочка отключает системный бэкап. Для PWA нельзя считать перенос данных браузера гарантированным. Проверить отдельно Android, Safari и установку с домашнего экрана.
- **Сервис FableShot.** Дал бы единый сценарий для разных устройств, но потребовал бы учётных записей, хранения, поддержки и проверки затрат. Возвращаться к нему, если интеграция с личным облаком окажется слишком сложной для пользователя.

Предлагаемый первый опыт — опциональное копирование после изменения дневника при ближайшем открытии приложения с сетью. Показывать дату последней подтверждённой копии, сохранять несколько версий и оставлять предыдущую доступной при прерванной выгрузке. Фоновый режим добавлять только там, где его поведение подтверждено на устройствах. На новом устройстве пользователь подключает то же хранилище, вводит заранее сохранённый код восстановления, выбирает версию, проверяет сводку и подтверждает восстановление. Код должен храниться отдельно от телефона. Потерю кода описать до включения функции. Выбор облачного провайдера, формата шифрования и периодичности остаётся для прототипа.

Критерий готовности будущего прототипа — восстановление в чистом профиле без исходного телефона, включая настройки и исходные архивы. Проверить отсутствие сети, сбой передачи, неправильный код, повреждённую последнюю версию и восстановление предыдущей. Облачное сохранение в текущий выпуск не входит.
