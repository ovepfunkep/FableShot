# Раунды — предложение для обсуждения

Статус: 2 ноября 2026. Пользователь попросил сначала обсудить план; реализация замечаний отца не разрешена этим обсуждением. Ни миграция, ни терминология интерфейса на «раунд» пока не менялись.

## Что есть сейчас

Тренировка → блок условий → серия → стрела. План количества серий относится ко всей тренировке. Стрелы фиксированы для блока (1–12), неполную серию можно закрыть, отдельного свободного режима стрел нет. На мишени сумма серии и всей тренировки, без среднего балла серии/раунда. Места и полноценной формы общей карточки условий пока нет.

## Предлагаемый порядок

1. Согласовать модель «Тренировка → Раунд → Серия → Стрела». Раунд — самостоятельный отрезок, даже когда условия предыдущего раунда не изменились. У тренировки дата/место и исходные настройки; раунд наследует оборудование, дистанцию, мишень с возможностью смены. Это предложение, не принятое решение.
2. Согласовать быстрый сценарий. Первый раунд создаётся при обычном старте; привычные условия уже подставлены. У раунда фиксированное/свободное число серий; у серий фиксированное/свободное число стрел. Не заставлять настраивать всё перед каждым занятием. Обсудить завершение раунда и переход к следующему, ограничения свободного ввода и смену условий.
3. Согласовать экран ввода. Два компактных итога: очки и средний балл серии, очки и средний балл текущего раунда. Общий итог тренировки — в статистике/по запросу. Состав видимых показателей ещё обсуждается.
4. После согласования обновить отчёты, историю и импорт. Разобрать соответствие существующих блоков и раундов MyTargets, не угадывать утраченные границы. Отдельно согласовать сохранение старого дневника и архивов; миграцию проверять на изолированных копиях. Области расчётов CG3/PG1 уточнять без пересмотра принятых формул.
5. Разрядная сетка: сравнивать только полное совместимое упражнение с проверенной редакцией норм; затем отметка присвоенного разряда в профиле. Само превышение норматива не означает официального присвоения.

## Утверждено пользователем — 2 ноября

- Обычная тренировка: один раунд с неограниченным количеством серий, как текущий свободный режим.
- Компактное отображение «Раунд N · Серия M» подходит. Если количество раундов и серий ограничено, показывать текущий/общее: «Раунд 1/2 · Серия 3/10». Для уровня без лимита только текущий номер; знаменатель не выдумывать.
- В условиях должна появиться возможность выбирать количество раундов. Стандартный пресет настраиваемой тренировки: 2 раунда × 10 серий × 3 стрелы. Этот пресет не заменяет обычную свободную тренировку.
- В «За раунд» текущие/максимальные очки: при известном плане максимум по числу серий и стрел, в свободном раунде только текущие очки, без дроби и знаменателя.
- На экране ввода справа от очков серии её средний балл; следующей строкой аналогично очки и средний балл раунда. Средний считается по фактически внесённым стрелам, включая M=0; пустые места не считаются нулями, пустая выборка — «—».
- Шестерёнка — классическая с зубцами и круглым отверстием.

Настройка нескольких раундов и изменение хранения пока остаются отдельным пакетом по прежнему ограничению пользователя. Текущий UI может показывать результат существующего блока условий; это не полноценная реализация новой модели раундов.

## Переходы — утверждено

Используется существующая нижняя кнопка. Обычный переход — «Следующая серия», на границе раундов — «Следующий раунд», в конце заданного плана — «Завершить тренировку». Новые кнопки и дополнительное подтверждение не требуются. Во время правки стрелы сохраняется отдельное действие «Готово». В свободной тренировке конец заранее неизвестен, поэтому кнопка остаётся «Следующая серия», ручное завершение доступно в шапке.

«Следующий раунд» подключается вместе с полноценной реализацией нескольких раундов; текущие блоки условий не получают выдуманной автоматической границы по десяти сериям.

## Закрытый вопрос об отображении

Насколько раунд должен быть заметен при обычной тренировке: всегда номер и самостоятельное завершение либо компактное отображение, пока раунд один? Рекомендация: номер виден компактно, полноценные настройки и дополнительные действия по необходимости.
