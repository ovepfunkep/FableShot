# Активный брейншторм

Название/иконка, профиль, турниры, анимации, темп комнаты, PG1, CG3 и компоновка лидерборда закрыты в [решённых вопросах](../resolved/README.md). Повторно выбирать их не нужно.

Техническая основа закрыта: [Android APK, Kotlin + Compose](../resolved/platform/README.md). Начата подготовка первого настоящего APK; альтернативы PWA/Flutter/Capacitor хранятся в решённых вопросах.

## Статистика и будущие отчёты

- [06. Структура статистики и подробные представления](06-statistics.md).
- [Реестр данных/метрик и предложенные отчёты](../metrics-and-reports.md).

Отдельное окно статистики каждой тренировки подтверждено. Пользователь поручил самостоятельно готовить широкий полезный набор; окончательный состав обсудить позже после определения данных. Выбирать сейчас каждый график не требуется. Сами исходные метрики сохраняются независимо от того, дают ли они надбавку CG3.

Первый прототип — точка доступа телефона: [сценарий и испытания](../local-room.md). Цель до 50 стрелков сохраняется, реальная вместимость раздачи требует испытаний. Интернет/облако — резерв.

- [09. Сравнение транспортов](09-group-mode.md).
- [10. Расходы и квоты интернет-резерва](10-group-costs.md).

Исследования остаются справочными темами до испытаний, а не просьбой повторно выбрать точку доступа.
