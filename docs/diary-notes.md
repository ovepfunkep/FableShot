# Записи дневника и ручной контекст — S23

Понятный самостоятельный подпакет: текст, дата, теги, место, самочувствие и условия. Поля необязательны, но пустая запись не сохраняется. Дата задаётся пользователем, начальное значение — текущая дата телефона. Это личные наблюдения, а не автоматический диагноз техники/здоровья.

Запись может быть отдельной либо привязана ко всей тренировке, группе сохранённых условий или серии. Отдельная запись не создаёт пустую тренировку/стрелы. Создание связанной записи доступно из условий тренировки, действий отчёта и окна серии; все записи доступны в «История → Заметки». Поиск находит текст/теги/ручной контекст. Заголовки связей различают настоящие раунды/серии и группы условий.

Редактор: текст, теги через запятую, дата, необязательные место/самочувствие/условия; сохранение с проверкой ревизии и ошибкой без закрытия, отмена с подтверждением несохранённых изменений, удаление с подтверждением. Фото и расширенная разметка остаются отложенными. Заметка не участвует в CG3/PG1/нормативах и не выдумывает измеренные данные.

Таблица diary_notes: UUID, необязательные sessionId/blockId/endId, календарная дата, текст, JSON тегов, ручные поля, моменты создания/правки, ревизия, tombstone. Ссылки проверяются на принадлежность одной тренировке; при физическом удалении пустого источника запись сохраняется с обнулением ссылок. Корзина тренировки не удаляет запись. Запись со связью на удалённую тренировку не выдаётся за активную тренировку.

Аддитивная миграция 8→9 создаёт только таблицу и индексы; архив 7 сохраняет записи и читает прежние 1–6 с пустой таблицей заметок. Основной дневник не открывается новой схемой до проверки отдельной копии и резервирования. Реальное состояние/проверки — в work-queue.md.
