# Личные рекорды

Первый общий подпакет: лучшая полная серия по классическим очкам и максимальный объём завершённой тренировки. Вход из профиля «Мои рекорды». Галерея Серии/Объём, поиск по дистанции/мишени/комплекту, переход к исходной тренировке. Поддерживаемые полные нормативные упражнения открываются отдельным действием; произвольные полные форматы пока не объявлены реализованными.

Очковая серия участвует только из завершённой, неудалённой тренировки: зачётная, закрытая, заполнена ровно до планового числа стрел, без примеси счётчика, с известной положительной дистанцией и подтверждённой мишенью. Старые ручные очки допустимы при известном профиле; координаты для классического результата необязательны. Неполные/открытые серии, разминка и неизвестная геометрия не становятся рекордом.

Ключ сопоставимости: дистанция, размер/ID/версия/каноническая геометрия мишени, точный сохранённый снимок снаряжения и число стрел. Неуказанный комплект — отдельная категория, не смешанная с известным. Такое строгое разделение соответствует текущим сохранённым условиям; изменение каталога не переписывает прошлую категорию. Один лучший результат по ключу; равные очки не являются улучшением. Из равных берётся самая ранняя известная дата, затем стабильный источник; недатированная запись остаётся без даты.

Рекорд хранит исходные ID тренировки/серии, ревизию сессии, версию правила full-series-classical-v1 и настоящие номер раунда/серии по плану. Это производная текущего дневника. Сводка держит только лучшие серии по ключу в каждой тренировке; галерея не перечитывает базы по одному занятию. Правка/корзина/восстановление пересчитывают победителя. Полные серии разных условий внутри одного занятия участвуют по отдельности.

Объём — максимум внесённых выстрелов в одной завершённой непустой тренировке, включая разминку и подсчёт без оценки. Это количество, не оценка техники и не общий очковый зачёт.

## Сохранённые сравнения и поздравления

При первом завершении собственной тренировки, включая автоматическое, записываются строгие улучшения лучшей полной серии, объёма и поддерживаемого полного упражнения в выбранной категории. Для упражнения сравниваются классические очки одного формата. История, включая импорт, может дать прежний результат. Равенство и первая попытка в новых условиях устанавливают ориентир для галереи без поздравления. Продолжение уже завершённой тренировки учитывается в галерее.

Карточка в отчёте хранит условия, прежнее значение, новое значение и разницу на момент завершения. Запись сохраняет версию правила, время, прежний источник и ревизию новой тренировки. Правки или корзина пересчитывают текущую галерею, а сохранённое сравнение остаётся снимком.

Короткий баннер AE02 показывает улучшение один раз. Одновременные рекорды идут в одной очереди с достижениями. Показ учитывает настройки поздравлений, скрытия результатов, анимации и вибрации. Открытие истории, перенос MyTargets и восстановление архива сами не запускают поздравления. Сохранённые сравнения переносятся в архиве FableShot формата 10; обновление с Journal 11 начинает журнал событий с пустой таблицы.

За обновление рекорда через календарный месяц уже действует достижение [«Ну наконец-то»](achievements.md#ну-наконец-то--новое-правило-progress10) в ветке лука. Поддерживаются сопоставимые полные серии и разрядные упражнения. Произвольные полные форматы остаются в очереди.
