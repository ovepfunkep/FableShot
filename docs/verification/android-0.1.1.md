# Проверка Android 0.1.1-dev

29 октября 2026, Xiaomi 14 / Android 16 / API 36. Установлена версия 0.1.1-dev, versionCode 2, пакет `app.fableshot.android.dev`.

## Исправления по обратной связи

- Предварительная оценка вынесена из круга лупы в отдельную контрастную плашку: над верхней лупой и под нижней, дальше от пальца.
- До появления лупы выдерживается 160 мс для распознавания второго пальца. Неподвижное удержание работает; короткий одиночный тап сохранён. Если второй палец появился позже этого окна, уже открытая лупа сразу закрывается.
- Обработчик жеста перенесён на всю область мишени, включая кнопки масштаба. События обрабатываются на Initial pass, до кнопок и прокручиваемого родителя. Любой замеченный второй указатель отменяет размещение до отпускания всех пальцев; отпускание одного не возвращает ввод.
- Масштабируемый рисунок и область мишени обрезаются по границам viewport. Рисунок не перекрывает следующие элементы экрана.

## Подтверждённые проверки

Сборка `assembleDebug assembleDebugAndroidTest testDebugUnitTest` — успешна. Три модульных теста геометрии — без ошибок.

На реальном Xiaomi запущен только класс `app.fableshot.android.TargetBoardGestureTest`: `OK (6 tests)`, 7,113 с. Он размещает изолированный экземпляр TargetBoard в тестовой Activity, не создаёт и не изменяет записи тренировок.

1. Короткий одиночный тап создаёт ровно одно попадание.
2. Второй палец через 45 мс: лупа не появляется, масштабирование не создаёт попаданий; оставшийся палец также не создаёт стрелу.
3. Второй палец на кнопке масштаба отменяет размещение.
4. Неподвижное удержание открывает лупу; геометрические проверки подтверждают положение плашки сверху/снизу относительно круга.
5. Второй палец после начала наведения закрывает лупу и отменяет ввод до завершения жеста. Следующий отдельный тап работает.
6. После увеличения до 7,6× пиксели контрольной области под мишенью сохраняют её цвет: кольца не рисуются за границами мишени.

Установка основного и тестового пакетов: `adb install --no-streaming -r` → `Success`. После тестов обычная MainActivity запущена: `Status: ok`, `LaunchState: COLD`. Обновление выполнено без очистки данных.

## Границы результата и продолжение

Эти проверки подтверждают перечисленные регрессии жестов и отрисовки. Они не заменяют ощущение от физического большого пальца и не подтверждают весь сценарий БД после перезапуска: ранее подготовленные PersistenceSmokeTest в этот запуск не включались.

Следующий отзыв пользователя: не возникает ли лишняя стрела при обычном pinch, хорошо ли видна внешняя оценка у середины и краёв мишени. Далее продолжить сценарий сохранения/правки/Undo/восстановления, затем контракт данных и CG3/PG1 по рабочей очереди. Браузерное демо не редактировалось.
