- Галерея с категориями/условиями, новые награды в отчёте, inline-пояснения персонажей. Снимки названия/описания/редкости и отметки показа переносятся архивом без повторного поздравления. Восстановление/откат не превращают pending-сохранение имени из архива в новое действие.
