## Реализация

PNG-постер тренировки дополнен общим средним баллом по внесённым оценённым зачётным стрелам. В знаменатель не входят незаполненные позиции, учёт объёма и внезачётные записи; M даёт ноль. Шкала полного поддерживаемого нормативного упражнения показывает ближайший достигнутый/следующий порог, положение результата и разницу в очках/среднем. Ниже первой ступени граница 0 не называется разрядом; выше последней показан максимум, без выдуманного следующего звания. Для неполных/несовместимых упражнений итоговой шкалы нет.

Файлы реализации: `export/TrainingPoster.kt`, чистый `export/PosterRankInterval.kt`; изменена версия приложения. Контракт: [training-share-poster.md](../training-share-poster.md).
