# Android 0.14.0 — заметки дневника

2 ноября 2026. 0.14.0-dev (29), Journal 9, Equipment 1, архив 7. [Контракт заметок](../diary-notes.md).

## Реализовано

История → Заметки: отдельные записи, дата, текст, теги, место, самочувствие и условия; поиск, правка, удаление с подтверждением. Записи можно создать из условий тренировки, отчёта и окна конкретной серии. Связь проверяется на принадлежность одной тренировке; отдельная заметка не создаёт занятие. Сохранение защищено ревизией, ошибки оставляют редактор открытым, отмена спрашивает о несохранённых изменениях. Черновик переживает пересоздание UI.

Аддитивная миграция 8→9 добавляет только diary_notes и индексы. Физическое удаление источника сохраняет текст с обнулением связи. Архив 7 включает заметки; матрица прежних форматов 1–6 проверяет сохранение старых таблиц и пустые будущие таблицы. Неверные даты/связи/поля отклоняются до замены дневника.
