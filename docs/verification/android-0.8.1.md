# FableShot 0.8.1-dev (21)

По просьбе пользователя сохранённый PDF сразу открывается через ACTION_VIEW после успешного завершения записи и закрытия потока. Передаётся URI именно сохранённого файла, application/pdf, временное право чтения и ClipData. При отсутствии просмотрщика/сбое открытия показывается, что PDF уже сохранён. Эти ошибки не предлагаются как повторная ошибка записи. Отмена системного выбора файла и ошибка записи не запускают просмотр.

Изменён ui/AnalyticsExportButton.kt. Схемы/данные/расчёты не менялись. Первая попытка сборки с расширенными правами завершилась таймаутом автоматической проверки; разрешённый повтор прошёл. assembleDebug: успех за 1m5s. Установка/запуск на Xiaomi 14 успешны, dumpsys подтвердил versionCode 21 / 0.8.1-dev. Новые тесты, повторяющие вызов Intent, не добавлялись; проход через реальный системный выбор места и просмотрщик пока не выполнялся автоматически. Проверка фактического открытия — следующий ручной отзыв пользователя.

APK artifacts/FableShot-0.8.1-debug.apk. Следующий функциональный пакет по очереди — подробный CSV. Сравнение двух периодов не возвращать.
