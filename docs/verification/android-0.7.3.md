# FableShot 0.7.3-dev (17)

Общая геометрическая статистика выбранной группы тренировок: точки или плотность в сетке 24×24, среднее попадание, RMS всех отмеченных точек вокруг общей средней, смещение и оси в миллиметрах. Белое кольцо обозначает среднюю точку; направления осей и охват подписаны. Плотность — точный счёт в ячейках без интерполяции, её максимум указан; размер ячейки зависит от масштаба карты. Видны все точки, включая выходящие за круг.

JournalSummaryMeta получает неперсистентный список подтверждённых координат. JournalDetails.summary включает только зачётные оценённые стрелы, positionStatus known, faceId main и известные согласованные профили; неподтверждённый импорт/числовые оценки/разминка исключены. Существующая группировка разделяет разные условия. При отсутствии координат показано объяснение, карта и нулевые измерения не рисуются. RMS доступен от трёх точек, смещение от одной. Общий RMS включает дрейф между занятиями и явно отделён справкой от внутриcерийного CG3. Формулы зачётов не менялись.

Одна сборка приложения и тестов за 28 s: geometry-build.log. 10/10 целевых Android-проверок за 6.233 s: GeometryAnalyticsTest (2), AnalyticsSelectionTest (2), TargetProfileRepositoryTest (6), лог geometry-analytics.log. Проверены охват 3/4, нулевой разброс плотной группы, смещение 30 мм, переключение плотности, отсутствие фиктивного нуля при неизвестных координатах, выборка и профили. Полный набор не повторялся.

Установлено на Xiaomi 14. Схемы не менялись. Перед обновлением создана и проверена .tools/backups/FableShot-2026-10-30T05-26-53-419Z: verified_schema_5, 8 занятий / 21 серия / 52 стрелы / 455 очков. Личные данные тестами не изменяются. APK artifacts/FableShot-0.7.3-debug.apk.

Файлы: ui/GeometryAnalytics.kt, DiaryScreens.kt, JournalPracticeStore.kt и неперсистентная JournalSummaryMeta; GeometryAnalyticsTest.kt.

Ограничения: общий экран пока исключает тренировки с разными условиями целиком; следующий пакет — выборка по отдельным блокам.
