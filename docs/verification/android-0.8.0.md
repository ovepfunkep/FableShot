# FableShot 0.8.0-dev (20) — экспорт PDF

В Прогрессе кнопка «Отчёт PDF · все группы». Экспорт берёт выбранные период/занятия, все группы условий по отдельности; пользователь явно видит этот состав перед сохранением/отправкой. Файл содержит очки/средний, распределение зон, карту подтверждённых координат, общий RMS/смещение, охват, список занятий каждой группы и полный состав выборки. Пустая выборка запрещена. Неизвестные условия/даты не выдумываются. Это PDF-отчёт, не архив; временные графики и полный CG3/PG1 в этот первый PDF не включены.

Формирование в Dispatchers.IO, отдельный файл в cache/reports. Android PdfDocument, фиксированные размеры страниц A4, перенос строк/абзацев и нумерация. Шрифт Manrope 400/700 из ресурсов приложения не зависит от системного шрифта телефона. Запись через CreateDocument, отправка ACTION_SEND только через chooser, с временным read-grant/ClipData; FileProvider не экспортирован и открывает только cache/reports. Автоматических отправок другим людям нет. Подготовка/сохранение показывают ошибки, повтор доступен. Исходники/база не изменяются.

Файлы: export/AnalyticsPdf.kt, ui/AnalyticsExportButton.kt, AnalyticsSelection.kt; общий analyticsConditionKey используется экраном и PDF. AndroidManifest и res/xml/report_paths.xml. Схемы не менялись.

Сборка 39 s (export-build.log), тестовый APK после добавления координат 5 s (export-test-build.log). 6/6 Android, 4.016 s (report-export.log): ReportExportTest (2), AnalyticsSelectionTest (2), AnalyticsBlocksTest (2). Проверены разделение условий, валидный PDF/чтение через FileProvider/PdfRenderer, пустой выбор/неизвестная дата и текущий отбор. После визуальной проверки системный пиксельный шрифт заменён на Manrope: сборка 10 s (export-font-build.log), 2/2 экспортных проверки 0.089 s (report-export-font.log). Реальный выбор внешнего приложения/места сохранения пользователем в автоматический прогон не включён.

Файл из тестовой Android-генерации извлечён в artifacts/verification/export-final.pdf и просмотрен постранично (3 страницы, export-final-page-1..3.png). Кириллица, диаграммы и карты читаемы. Есть косметическое ограничение: заголовок следующего раздела иногда остаётся внизу страницы. Дополнительная правка удержания заголовка не включена в установленную сборку: два запуска с расширенными правами отклонены из-за таймаута автоматической проверки разрешения, запуск без расширенных прав не собрался. Непроверенная правка возвращена к последней проверенной версии. Отдельная задача доводки, не потерять.

Установлено 0.8.0-dev на Xiaomi 14; APK artifacts/FableShot-0.8.0-debug.apk соответствует прошедшей проверку версии со встроенным шрифтом. История не редактировалась тестами. Подробный CSV, изображение отчёта и дополнительные секции PDF остаются впереди; сравнение двух периодов отменено пользователем и не возвращается в план.
