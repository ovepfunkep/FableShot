# Проверка FableShot 0.11.0-dev (26)

2 ноября 2026. Journal v7, Equipment v1, архив формат 5.

## Выполнено

Контракт [rounds.md](../rounds.md): обычный свободный режим, настраиваемый одинаковый формат раундов с пресетом 2×10×3, независимость от блоков условий, дробные счётчики, очки/средние текущего раунда, три подписи одной кнопки, повтор/привычный план, подписи в отчёте и редакторе. Подсказки подготовки и мишени удалены.

Пустая служебная серия при смене условий в многораундовом плане удаляется, а опустошённая последующей правкой уже закрытая серия сохраняет своё место. Это предотвращает сдвиг границ раундов. У старых однораундовых планов прежняя семантика сохраняется. Запретить отдельно закрывать пустую зачётную серию в новом многораундовом плане; штатная кнопка и раньше доступна только после заполнения.
