# FableShot 0.8.2-dev (22) — подробный CSV

В меню экспорта Прогресса выбор PDF или CSV FableShot. CSV — UTF-8 BOM, разделитель ;, CRLF, все ячейки в кавычках с удвоением внутренних кавычек. Десятичные значения используют точку. Строки shot содержат устойчивые ID, сессию/версию, исходную дату/источник, условия/снимки мишени/снаряжения, блок/серию/роль, порядок ввода, очки/M/X, автоматическую оценку/правило, координаты/лицо/достоверность/источник, номер стрелы и редакцию/время записи. Порядок ввода не называется порядком физических выстрелов.

Для счётчика строка count с объёмом, без фиктивных оценённых стрел; пустые серия/блок/занятие сохраняются типами empty_end/block/session. Неизвестные поля пусты. Неподтверждённые исходные координаты экспортируются с их настоящим position_status, а не выдаются за подтверждённые. Разминка и все условия выбранных занятий включены явно; это сырой экспорт, не только строки, вошедшие в агрегированные графики. Это собственный формат FableShot, не MyTargets и не замена полного архива.

Строковые значения, похожие на формулы Excel (=,+,-,@ с возможными начальными пробелами или управляющими символами), защищаются ведущим апострофом; typed numeric координаты не изменяются. Это преобразование текста описано в диалоге; CSV не объявляется точной резервной копией. Исходники сохраняются в дневнике/архиве.

Перед экспортом каждой выбранной сессии загружаются полные детали, проверяются state/deletedAtMs/ожидаемая revision. При исчезновении/изменении записи файл не формируется частично, предлагается обновить выборку. Запись файла потоковая, но список деталей выбранных занятий пока в памяти. Формирование в IO. Отдельные CreateDocument-контракты сохраняют правильные MIME PDF/CSV; после успешной записи сохранённый URI открывается тем же форматом. Отправка только через системное меню, read-grant и ClipData; автоматической отправки нет.

Файлы: export/AnalyticsCsv.kt; AnalyticsExportButton, AnalyticsSelection, PracticeShell (загрузка model.details по выбранным ID). Схемы не менялись.
