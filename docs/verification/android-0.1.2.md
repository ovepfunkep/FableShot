# Проверка Android 0.1.2-dev

29 октября 2026. Xiaomi 14, Android 16 / API 36. Пакет `app.fableshot.android.dev`, versionCode 3. Последнее уточнение пользователя заменяет поведение лупы/границ из 0.1.1.

## Реализовано

- Лупа всегда сверху, оценка над кругом. Общий TargetOverlayHost рисует её поверх интерфейса, за пределами области мишени. Это слой того же окна без Popup и без обработчиков касаний, способных перехватить второй палец.
- Мишень рисуется на всю ширину доступной области экрана. Удалены фиксированные 300 dp по ширине и внешние горизонтальные отступы; отступы сохранены только у текста/кнопок. Высота открытого окна ввода остаётся 300 dp, исходный физический масштаб координат сохранён.
- Сцена мишени продолжается под верхней панелью условий/серии и нижней панелью действий. Их фон повторяет ту же геометрию мишени со смещением в координаты панели, размывает только этот рисунок и накрывает оттенком текущей темы с непрозрачностью 76%. Текст и элементы управления рисуются отдельно без размытия. Не используются скриншоты, сетевые сервисы или новые библиотеки.
- На Android 12+ используется BlurEffect; на более старых API остаётся полупрозрачная подложка без аппаратного размытия. Фактически проверен Android 16.
- Общий наблюдатель жеста отменяет размещение, если второй палец попал на панель вне открытого окна мишени. Панели не добавляют попаданий, их элементы управления сохраняют назначение.

## Проверки

`assembleDebug assembleDebugAndroidTest testDebugUnitTest` — BUILD SUCCESSFUL. Модульные тесты геометрии — 3/3.

На телефоне запущен только изолированный `TargetBoardGestureTest`: **OK (8 tests)**, 10,147 с. Пользовательские записи тренировок не создавались и не изменялись.

1. Одиночное касание создаёт одну стрелу.
2. Второй палец через 45 мс не вызывает вспышку лупы или попадание.
3. Поздний второй палец отменяет уже открытое наведение до отпускания всех пальцев.
4. Второй палец на кнопке масштаба отменяет попадание.
5. Лупа всегда выше пальца и может выходить над окном мишени поверх шапки; оценка остаётся над кругом.
6. Рисунок не выходит за общий блок сцены в независимый контент.
7. Окно мишени занимает всю ширину корневого экрана; после увеличения рисунок доходит до обоих краёв. Пиксели верхней и нижней подложек меняются вместе с мишенью, подтверждая продолжение сцены под ними.
8. Второй палец на верхней стеклянной панели отменяет ввод.
