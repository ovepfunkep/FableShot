# Android 0.15.1 — личные рекорды

3 ноября 2026. 0.15.1-dev (33), Journal 9/Equipment 1/архив 7, без миграций. [Контракт](../personal-records.md).

Из профиля доступны рекорды полных серий по одинаковым условиям, поиск и отдельный рекорд объёма. Карточка открывает исходную тренировку; переход к поддерживаемым нормативным форматам сохранён. Закрытые полные зачётные серии завершённых тренировок участвуют, неполные/разминочные/открытые/с неизвестной мишенью — нет. Дистанции, размеры/профили, снимки комплектов и число стрел не смешиваются. Правка/корзина/восстановление пересчитывают победителя; равенство не является улучшением. Реальные номера раунда/серии берутся из плана.

Сводки держат только лучшие серии по условиям внутри занятия; галерея не делает отдельный запрос на каждую тренировку. Канонический снимок мишени формируется один раз на группу условий, а не заново для каждой серии. Масштабный замер на 4000 реальных занятиях не проводился.

Выполнено:

- `artifacts/personal-records-build.log`: assembleDebug, assembleDebugAndroidTest, **68/68 JVM**. Новые проверки — сопоставимость, равенства, исправление/удаление/восстановление источника.
- `personal-records-device.log`: **5/5 Android** — два сценария адаптера/раундов/объёма, полный UI профиль→рекорд→источник→корзина→замена→восстановление, галерея достижений с условием/источником/шрифтом 200%, полный архив.
- `personal-records-ui-build.log`, `personal-records-ui-device.log`: сборка тестов и **1/1** отдельный UI рекордов с шрифтом 200%, поиском/пустой выборкой и открытием источника.
- После устранения повторной сериализации мишени: `personal-records-final-build.log` — успешная сборка APK; `personal-records-final-device.log` — **2/2** целевых проверки адаптера. Повторять неизменившуюся полную матрицу не потребовалось.
- Просмотрены `artifacts/design/records/personal-records.png` и `records-large.png`; на первом список прокручен, поэтому верхняя кнопка частично за шапкой. Это положение прокрутки снимка. Финальный APK установлен, MainActivity открыт (`personal-records-final-install.log`, `personal-records-final-launch.log`). `artifacts/FableShot-0.15.1-debug.apk` и latest одинаковой финальной сборки.

Также прогресс полученного достижения ограничен его порогом в UI, поэтому «Первый шаг» показывает 1/1, а не 5/1; исходное фактическое число не меняется.

Не реализованы сохранённые исторические версии сравнений/события рекордов, автоматические праздники и произвольные полные форматы вне поддерживаемых нормативов. X входит в десятку; отдельного рекорда по X/кучности в этом подпакете нет. Переход открывает тренировку целиком. Тесты изолированы, личный дневник не очищался.
