# FableShot 0.7.4-dev (18)

Завершённое многоблочное занятие теперь участвует в аналитике отдельными группами условий. Группировка включает режим, дистанцию, профиль/версию/снимок мишени, размер и снимок снаряжения. Одинаковые блоки одного занятия объединяются в одну точку: A→B→A даёт два результата, не три тренировки. Дата, ID занятия и ручной отбор сохраняются. В шапке остаётся количество настоящих занятий, причины исключения считаются по частям занятий.

Неперсистентная JournalSummaryMeta содержит analyticsParts; дочерние сводки не имеют вложенных частей. Summary истории остаётся целым занятием. analyticsRows раскрывает части только на экране аналитики и в его предупреждении. Средний, зоны, координаты, карта и динамика используют одинаковую группу. В подписи группы доступно название сохранённого комплекта. Ключ условий теперь всегда включает снимок комплекта, а не только категорию лука; правила замороженного PG1 не изменялись. Для объединения нескольких блоков PG1 не усредняется и не придумывается.
