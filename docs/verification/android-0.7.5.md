# FableShot 0.7.5-dev (19)

В экран Прогресс добавлена GeometryTrend: переключение RMS/смещения от центра, график в мм с явной автоматической шкалой, даты, список значений и охват координат каждого занятия. Участвуют только занятия выбранной группы минимум с тремя подтверждёнными координатами. Для меньшего объёма показана недоступность, не фиктивный ноль. При неполном охвате есть предупреждение.

График показывает последние 12 доступных занятий, сравнение первого/последнего относится ко всей выбранной группе. Уменьшение/увеличение названы человеческим языком, изменения показаны в мм; относительный процент есть только от ненулевого первого значения. Меньше — лучше для обоих показателей. Не PG1 и не внутриcерийный бонус CG3. Ось X — порядок учтённых занятий. Для одинаковых условий одного занятия используются объединённые блоки, как в 0.7.4. Источники/формулы зачётов/схема хранения не менялись.

Одна сборка, 18 s (geometry-trend-build.log). 8/8 Android, 7.803 s (geometry-trend.log): GeometryTrendTest (2), GeometryAnalyticsTest (2), AnalyticsBlocksTest (2), AnalyticsSelectionTest (2). Проверены нулевая исходная величина, перевод .1 радиуса при диаметре 600 мм в 30 мм, отсутствие процента от нуля, недостаток координат, карта и общая выборка. Полные наборы повторно не запускались.

Установлено на Xiaomi 14. APK artifacts/FableShot-0.7.5-debug.apk. Файлы ui/GeometryTrend.kt, включение в DiaryScreens.kt, GeometryTrendTest.kt. Личные тренировки не редактировались тестами, миграций нет. Следующая точка — сравнение двух периодов с согласованными условиями, объёмом и охватом; экспорт и оптимизация большой истории ещё впереди.
