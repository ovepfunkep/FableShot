# Плавное обновление данных

Решение пользователя от 2 ноября 2026: обновления по всему приложению должны быть плавными; при отметке попадания цифры сдвигаются вместо мгновенной подмены. В 0.12.0 общий компонент подключён к основным числовым показателям тренировки/карточек/отчёта и нормативной шкале. Остальные пункты — общий стандарт последующих экранов; все движения приложения не объявлены готовыми.

- Общий компонент для очков, средних серии/раунда, счётчиков и прогнозов: новое значение въезжает, старое уходит в пределах собственной области. Рекомендуемая длительность 180–240 мс; направление по росту/снижению — обратимая техническая деталь.
- Геометрия стабильна: табличные цифры, достаточная ширина под ожидаемый формат, неизменные высота/выравнивание. Никаких новых переносов и сдвига соседних элементов. Переход не перекрывает мишень/кнопки.
- Переход между фактическими значениями, без перебора выдуманных промежуточных очков. Смена «—» тоже плавная. Равное значение не запускает эффект.
- Быстрый ввод перенаправляет переход к последнему значению без очереди. Сохранение и следующий ввод не ждут анимации.
- Первое открытие, обычная рекомпозиция и возврат карточки на экран не воспроизводят несуществующее изменение. Доступность получает конечное значение без промежуточного спама.
- Шкалы, графики, фильтры и изменения состояния используют согласованные короткие переходы. Подписи/подсказки показывают реальные данные, не промежуточные кадры.
- Не анимировать весь экран на каждое нажатие, без мигания карточек. Лупа, зум и редактирование остаются отзывчивыми.
- Праздник рекорда/подтверждённого результата — отдельное событие. Колебания прогноза и повторный просмотр не запускают награду.
- Полный режим движения — сдвиг; спокойный — короткий мягкий переход без выраженного перемещения; выключенный или системное отключение — сразу конечное состояние. Вибрация отдельно.

Проверка при внедрении: ввод/правка/отмена, одинаковые значения, быстрые действия, 9→10 и 99→100, M/пустое значение, крупный шрифт, возврат на экран и все режимы движения. Соседние элементы не меняют геометрию. Внедрять общим компонентом по затронутым экранам.

3 ноября: у таймера MM:SS отдельные неподвижные ячейки разрядов. Анимируется только изменившаяся цифра; пиксели неизменного префикса/двоеточия проверены в середине перехода. Локальная правка попадания удерживается до подтверждения ревизии, поэтому выбор следующей стрелы не возвращает старую позицию промежуточным кадром.
