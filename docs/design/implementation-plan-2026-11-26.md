## A. Нормативы и категория профиля

**Сценарий.** Лучник завершил два зачётных раунда и начал третий. В результате и в «Лучших по нормативам» он видит зачёт первых двух, а в общей статистике — все выстрелы.

1. В `exercise-rank.ts` заменить проверку общего числа стрел на выборку зачётных раундов. Сейчас проверяются все непустые серии сразу, поэтому 30+30+3 не проходит. Отбирать раунды в исходном порядке. Пустые пропускать. Один зачётный раунд имеет единые спортивные условия — класс лука, дистанция, профиль и диаметр мишени. Идентичность комплекта и отдельных стрел игнорировать для норматива. Учитывать нули и промахи как введённые выстрелы.
2. Определять полноту по фактическим данным. Для лимита по стрелам раунд полный при точном достижении лимита. Последняя серия может быть короче, если именно она исчерпала лимит. Для лимита по сериям нужны ровно столько непустых полных серий. Полноту старой серии без `plannedCount` определять прежним правилом `shots.length === max(3, shots.length)`. Для безлимитных и импортированных раундов без достоверного лимита брать только раунд объёма поддерживаемого упражнения или точной его половины, с полными сериями. Полнота упражнения подтверждается при завершении тренировки. Во время ввода показывать темп.
3. Группировать полные раунды по спортивным условиям. Для одного формата выбирать первое подходящее упражнение в хронологии завершения — один полный раунд точного объёма или ровно два полных раунда по половине объёма. Для 60 используются 30+30, для 72 — 36+36, если такой формат есть в справочнике. Между двумя половинами можно пропустить неполный раунд или раунд с другими условиями. Результат пары заканчивается на втором принятом раунде. При наличии трёх полных половин брать первые две, не подбирать самую выгодную пару. 60+60 не образует упражнение на 120 при отсутствии такого формата. Если двух половин нет, показывать 30 как самостоятельный зачёт, если есть соответствующая строка, иначе темп. Не создавать в «Лучших» дополнительный результат на 30 из половины уже зачтённой пары.
4. Возвращать из расчёта использованные ID и номера раундов, зачтённый объём и причины исключения. Для отчёта выбирать подтверждённый основной формат наибольшего объёма, при равенстве — первый завершённый по хронологии. «Лучшие по нормативам» сравнивают подтверждённые результаты отдельно по строкам справочника. Равные результаты оставляют первого по дате и существующему стабильному порядку ID. Ниже первого порога показывать тире. В отчёте выводить компактно «60 стрел · раунды 1 и 2» и пояснение, если есть лишние полные или неполные раунды. В строке результата норматив должен ясно относиться к зачтённым стрелам. Общая сумма и среднее относятся к целой тренировке.
5. Переиспользовать `matchingRankExercises` и `evaluateRank` из `sport-ranks.ts`. Проверить потребителей `PersonalRanksScreen.tsx`, `ExerciseRankCard.tsx`, `TrainingReportMetrics.tsx`, `JournalTabs.tsx`, `report-export.ts`, `progress-timeline.ts`, `personal-record-events.ts`, `training-moments.ts` и правила достижений. Новый расчёт применяется при просмотре и при фиксации новых результатов. Существующие записанные сравнения и выданные награды сохраняют прежние основания, даты и баллы. Если результат старого правила повторно валидируется из текущего дневника, выбирать версию правила по сохранённому основанию, а для версии без нового поля оставлять старую формулу.
6. `preferences.rankCategory` остаётся единственным сохранённым полем. В `ProfileScreen.tsx` добавить «Пол для нормативов» с вариантами «М», «Ж», «Не указан». В `SportRanks.tsx`, `ExerciseRankCard.tsx` и `PersonalRanksScreen.tsx` подставлять категорию из профиля. Без неё показывать «Указать пол в профиле» и не считать мужскую категорию молча. В `main.tsx` открывать нужную строку профиля и сохранять страницу, позицию и выбранный раунд для обратного перехода. При установленном поле дать локальное переключение М ↔ Ж для сравнения, явно обозначив предпросмотр другой категории. При повторном открытии снова брать значение из профиля. Переключатель не меняет профиль, записи и достижения. Убрать старые элементы, которые сохраняют пол прямо в окне нормативов. Если онбординг показывает раздел, вести к той же настройке профиля.

**Приёмка.** На образцах 30+30+3 и 30+3+30 зачтено 60, второй случай показывает раунды 1 и 3. Для 30+30+30 и 30+30+30+30 зачтены первые два, даже если последние набрали больше. Для 30+30 с разными мишенями общего зачёта нет. Проверить 36+36, отдельные 60 и 72, неполную середину, пустой хвост, короткую финальную серию под лимитом стрел, несколько упражнений, изменение и удаление раунда, смену комплекта того же класса, точную границу разряда и старые записи. Расширить `exercise-rank.test.ts`, тесты рекордов и сценарий профиля в браузере.
