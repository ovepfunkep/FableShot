## Общий клиент React — 0.26.3

**0.26.3.** Первый выпуск для проверки обновления Android через GitHub Releases поверх 0.26.2. Изменён номер версии и код APK (35), формат дневника прежний.

**0.26.2.** Вокруг мишени добавлено кольцо «Мимо» шириной в одну обычную зону. Касание кольца записывает ноль очков и координаты направления. Если габарит задевает зачётное поле, начисляются очки поля. Кнопка M сохраняет промах без координат. Промах с координатами виден на мишени и в лупе, отмечен крестиком на карте и в PDF, координаты входят в CSV и веб-архив. Для хранения используется необязательное поле `missPoint`, поэтому старые записи читаются как раньше. Координаты промаха исключены из плотности, RMS, смещения и бонуса за кучность CG3. Замена попадания в редакторе удаляет устаревшее направление. Веб-сборка и 324 теста логики прошли.

Прошли 11 браузерных сценариев, включая запись промаха, карту, редактирование, зум и экспорт. Оба React APK 0.26.2 (34) собраны и установлены поверх прежних копий на Xiaomi, версия обоих пакетов подтверждена. Релизный файл для будущей публикации — `artifacts/FableShot-android-34.apk`. Проверки касаний выполнялись в браузере.
