# Спортивные разряды и звания

## Выборка уровня после 0.30.0

Уточнение 0.30.1: уровень / класс лука размещены двумя короткими строками справа от очков и среднего внутри плиток, без отдельного ряда под результатом. В отчёте отметка справа в той же строке, что итог раунда.

В активной тренировке две отдельные отметки справа снизу плиток относятся к стрелам соответствующего раунда и выбранной серии. Тап по отметке открывает её разбор и доступ к сетке; тап по самой плитке — выбор раунда/серии. До полного нормативного упражнения это прогноз среднего, а не присвоение разряда. Справочный формат выбирается по сохранённому объёму раунда, если такой формат поддержан, иначе по поддержанному полному упражнению; отсутствующие пороги не достраиваются.

Отчёт содержит уровень каждого раунда, без дополнительного перечня уровней серий. История показывает общий уровень только при совместимом формате: среднее взвешено по стрелам, а не взят лучший раунд; разные форматы обозначаются их количеством. Категория сравнения явная. Проект наград за новые уровни — [отдельный каталог](design/stage-rank-achievements.md), без включения новых правил начисления.

Пожелание пользователя от 30 октября 2026: разрядная сетка в приложении, сравнение набранного результата с нормативом и отметка заслуженного разряда в профиле. Первый рабочий пакет реализован в 0.12.0; границы и проверки — в verification/android-0.12.0.md. 2 ноября пользователь вернул задачу в ближайшую очередь: приступить после текущего пакета UX/UI.

## Последнее согласованное уточнение — 2 ноября

По последней просьбе пользователя подпись «По темпу» заменена на «Разряд». Во время тренировки это по-прежнему прогноз по текущему среднему; официальное присвоение в профиле остаётся отдельным понятием.

Компактная строка в тренировке строго использует общую сетку очков: «Разряд» в левой колонке вместе с «За серию»/«За раунд», порог следующего норматива в правой вместе со средними. Единые отступы, межколонник и ширина правой колонки задаются TrainingMetricRow, а не независимо по длине текста; отсутствие доступного порога не расширяет левую колонку.

Исправление окна по пользовательскому скриншоту: главный вывод «Разряд — уровень» выше вторичных настроек. Названия разрядов привязаны к фактическим позициям рисок; при плотности распределяются по непересекающимся уровням с соединительными линиями, не раскладываются равномерными кнопками. Текущий средний — акцентный кружок, следующий рубеж — отдельный информационный цвет. Касание названия открывает описание порога. Указаны размер/профиль мишени; известная категория меняется через компактную строку с карандашом, неизвестная выбирается явно. Следующий порог описывается один раз, средний оставшихся стрел — только в подробном окне. Разовые сведения о присвоении/редакции/источнике скрыты под inline-термином «ЕВСК», с открытием описания и ссылки. Шкала 0–10 и формулы сохраняются.

Этот раздел заменяет противоречащие ему предварительные предложения ниже. Первый рабочий пакет: [реализация и ограничения](verification/android-0.12.0.md).

- **Перед стартом не добавляем выбор нормативного упражнения.** Подбираем совместимый формат по существующим условиям/плану. Неизвестную категорию или неоднозначный справочный формат уточняем в разборе, без догадок и без дополнительного шага запуска. Условия автоматически не меняем.
- В условиях тренировки выбирается только комплект (либо отсутствие снаряжения). Тип лука для норматива читается из сохранённого снимка лука внутри комплекта; редактирование каталога не переписывает этот снимок и результат прошлой тренировки. Старые отдельные снимки сохраняются для истории, но не выбираются заново через подготовку.
- **Разрядных целей нет.** Следующий рубеж — справочная информация. Предварительные предложения выбора/хранения цели ниже отменены; будущие общие цели приложения этим не отменяются.
- В тренировке компактное **«Разряд: II»**. Нормативный средний следующей ступени можно показывать рядом: порог полного упражнения / необходимое число стрел. Необходимый средний **оставшихся** стрел — только по нажатию: (порог − набранные очки) / оставшиеся стрелы. Эти показатели подписывать различимо. После последней стрелы деления на ноль нет; недостижимый рубеж объясняется в разборе.
- После успешного завершения сразу открываем статистику конкретной тренировки, отдельный блок **«Нормативы»**.
- Главная визуализация блока — горизонтальная **шкала среднего балла 0–10**. Риски начала разрядов стоят на порог / число стрел. Текущий средний — отдельный заметный указатель с числом. M=0 включён, пустые поля исключены; до первого попадания указателя нет. Плотные подписи разводятся по уровням либо раскрываются нажатием, без наложений.
- Шкала среднего не подтверждает необходимый объём упражнения. Неполный формат показывает темп, а не окончательный разрядный результат. В свободной тренировке допускается справочное сравнение темпа с явно указанным совместимым форматом; длина занятия не угадывается, лучшие стрелы не отбираются. Для правил с иным максимумом стрелы шкала 0–10 не должна создавать ложное сопоставление.
- В профиле остаются отдельно присвоенный разряд и лучший тренировочный результат; автоматически официальный разряд не повышаем.
- **Плавные обновления по всему приложению**, а не только разрядам: цифры при вводе сдвигаются вместо мгновенной подмены. Общий контракт: [value-updates.md](design/value-updates.md). Анимация не блокирует ввод и не сдвигает соседние элементы.

## Источник и данные норм

[Присланная таблица](references/sport-ranks-reference.png) сохранена как пример ожидаемой сетки. Дата, редакция и юридический статус изображения неизвестны; цифры из него не становятся автоматически действующими нормативами.

Перед реализацией подобрать и проверить официальный источник для выбранной страны/системы классификации, редакцию, срок действия и условия выполнения. Для РФ проверить соответствующую ЕВСК и документы по стрельбе из лука. Каждая таблица хранит источник, версию, даты применимости, дисциплину/тип лука, дистанцию, формат, число стрел, правила мишени/оценивания и категории участника, если они необходимы для нормы. Состав разрядов/званий, в том числе юношеских, определяется проверенными документами. Сроки действия присвоения не угадываются.

Обновление сетки не переписывает исторические сравнения: сохраняются использованная редакция и контекст. Если нет проверенной нормы или обязательных условий, сравнение недоступно с перечнем недостающих данных.

## Разрядная сетка

Отдельный экран из Прогресса и профиля: выбор дисциплины, формата и требуемых категорий; границы результатов, подходящий уровень и следующий рубеж. Рядом — число стрел и полные условия формата. Источник и редакция доступны по кнопке справки.

Можно открыть норматив без тренировки как справочник. Неизвестные личные параметры не предполагаются. Категорию для конкретного сравнения пользователь может указать без обязательного постоянного хранения лишних персональных данных.

## На какой уровень настрелял

В разборе совместимого полного упражнения показывать: фактические классические очки, результат сравнения, использованную сетку и сколько очков до следующего уровня. Пример подписи без утверждения официального присвоения: «По очкам — уровень …».

Проверять полное соответствие формата: зачётные стрелы, количество, дистанция, лук, мишень/десятка и необходимые категории. Разминку исключать. Не собирать норматив из произвольных лучших серий или разных условий. Для специально выбранного контрольного упражнения сохранять конкретные серии и проверять правила его комплектования. Смешанные занятия, неполный формат, импорт с неизвестными условиями и счётчик без оценки не дают выдуманного разряда.

Использовать классические очки; надбавки Общих/CG3 и Прогрессивные/PG1 не заменяют результат упражнения. Иные обязательные условия официального выполнения проверяются по источнику. При неизвестных условиях показывается только допустимое сравнение очков с оговоркой, а не сообщение о присвоении.

## Разряд в профиле

В профиле присвоения представлены компактной плиткой с пьедесталом, текущим разрядом и карандашом. При нескольких текущих дисциплинах плитка показывает их число, не выбирая общий максимальный разряд. Карандаш открывает все присвоения: текущие и историю, редактирование и добавление. Лучшие тренировочные нормативы остаются отдельной компактной плиткой со входом в результаты и разрядную сетку.

Реализовано в 0.13.0: отдельные ручные отметки rank_assignments (Journal 8), текущие по дисциплине/М/Ж и история, необязательные дата/кем присвоен/приказ. Новый текущий разряд переводит прежний в историю в одной транзакции; редактирование проверяет ревизию, повтор сохранения не дублирует запись. Удаление с подтверждением оставляет tombstone в архиве. Удаление текущего не назначает автоматически старый разряд. Дата/срок окончания не угадываются, «текущий» — явная отметка пользователя. Тренировочные расчёты не пишут в эту таблицу. Архив 6 переносит все поля, прежние архивы 1–5 создают пустую таблицу.

Пользователь указывает присвоенный разряд/звание, дисциплину, дату присвоения и при желании сведения о подтверждении. Поле необязательно. Видны текущая отметка и история прежних присвоений; разные дисциплины не сводятся автоматически к одному «максимальному разряду».

В профиле показывать понятный значок и название. Самостоятельно внесённые сведения обозначать как указанные пользователем, без обещания внешней проверки. Тренировочное превышение норматива автоматически не меняет присвоенный разряд. Истечение/актуальность показывать только при известных правилах или ручной отметке, не по придуманному сроку.

Разрядные цели не добавляются; следующий рубеж показывается справочно.

## Связь с остальными разделами

- Аналитика: сравнение полного совместимого упражнения и динамика дистанции до следующего рубежа.
- Профиль: присвоенные разряды/звания и история.
- Турниры: связь официального результата/подтверждения с участием, без автоматического присвоения от приложения.
- Архив: перенос отметок, редакций сетки и сохранённых сравнений. Импорт чужого дневника не объявляет официальное присвоение.

## Критерии готовности

1. Сетка имеет проверенный источник, редакцию и условия.
2. Подходящий полный результат сравнивается правильно на границах норм; неполные/несовместимые данные не получают ложного уровня.
3. Превышение нормы в тренировке не меняет присвоенный разряд профиля.
4. Обновление таблиц и правка результатов сохраняют происхождение сравнения.
5. Разряд и история переживают архив/восстановление.

Формат сопоставляем с существующими условиями и планом; неизвестную категорию/неоднозначный формат уточняем в разборе. Пол и возраст не выводим из имени; обязательное хранение даты рождения не требуется.

Первый набор — проверенные поддерживаемые форматы 18 м и совместимые форматы 50/70 м, если они присутствуют в выбранной официальной редакции. Окончательный список определяется документом, не этой фразой. Числа из картинки не копировать. Дисциплины с финалами/местами/специальными условиями не сводить к одному порогу очков. ### Во время тренировки — согласовано

Уточнение интерфейса 3 ноября, выбран F: **«Разряд» — строка под двумя плитками Раунд/Серия**, с классом (`КЛб(М)`), уровнем (`II`) и следующим порогом (`I от …`). Вся строка и подчёркнутое слово «Разряд» открывают существующий разбор. При крупном шрифте/узком экране строка адаптируется без микрокегля и без изменения высоты от новых очков. КЛ/БЛ/КЛб и М/Ж берутся из снимка лука/настройки, неизвестные не угадываются. Полная числовая сетка открывается действием «Вся разрядная сетка» в разборе; отдельной кнопки на мишени нет. Прежний компактный вид в других контекстах не меняется. Пустой/недоступный результат занимает те же слоты; скрытие результатов убирает весь разрядный блок и его подписи.

Справочник содержит все 33 строки числовых норм листа «Нормы КЛ БЛ» официального XLS: КЛ, бесприцельный КЛ (КЛб), БЛ и 3Д, включая юношеские ступени. М/Ж переключаются только для просмотра, не меняя сохранённую категорию тренировки. В таблице сохранены исходные названия упражнений, условия возраста, отдельные строки 30/60 стрел и пустые пороги (тире). Большая таблица прокручивается по двум осям, размеры ячеек учитывают системный шрифт. Справка ЕВСК и полный исходный документ доступны из окна. Правила по местам из остальных листов доступны в исходном документе, не превращаются в числовые баллы. Справочные форматы не расширяют автоподбор нормативов.

Отдельной кнопки «Нормативы» в тренировке нет; разбор открывается по «Разряд». Компактный прогноз «Разряд: II» (пример без нормативных чисел) без цели; рядом допустим нормативный средний следующего уровня. Предлагаемый вид: [варианты живого блока](resolved/sport-ranks-live.md). Уровень означает темп числового результата, а не присвоенный разряд.

Прогноз считается по всем уже внесённым стрелам выбранного упражнения: projectedScore = currentScore / enteredCount × requiredArrowCount. M=0 участвует; пустые стрелы не участвуют. Ничего не округлять вверх до порога: сравнение по точной величине, округление только для показа. Отдельно доступен требуемый средний оставшихся стрел до следующего рубежа, только по нажатию: (threshold − currentScore) / remainingArrows; если значение выше допустимого максимума стрелы, рубеж недостижим в этом упражнении. Если порог по сумме уже пройден до окончания упражнения, показать достигнутый числовой порог, но не объявлять упражнение завершённым. После последней стрелы не делить на ноль — использовать фактический итог.

В первом пакете прогноз показывается с первой введённой стрелы и обновляется при внесении/правке; предварительная задержка на две серии не применяется. Это прозрачная линейная оценка текущего темпа, не вероятностная модель и не обещание результата. Доверительный интервал и предсказания изменения техники в первый выпуск не включать.

Норматив относится к полному упражнению, которое может включать несколько раундов. Показатель не обнуляется при переходе между раундами этого упражнения; очки/средние раунда продолжают считаться отдельно.

В свободной тренировке лимит не угадывается. Допустим справочный прогноз по совместимому формату, явно указанному в разборе. Финальное сравнение требует полного совпадения объёма и условий. Из длинного занятия не выбираем лучшие стрелы; автоматическое выделение нормативных отрезков в первый выпуск не входит.

### Завершение и блок нормативов — согласовано

После подтверждённого завершения тренировки открывается её статистика: как по ручному завершению, так и по последней серии плана. Переход только после успешной записи, открывается конкретный завершённый sessionId. Восстановление процесса не завершает другую тренировку и не создаёт повторную награду. Отмена завершения оставляет экран ввода; ошибка сохранения не показывает выдуманный итог.

Отдельный блок «Нормативы» содержит: упражнение и категорию, фактические очки, «По очкам — II разряд», разницу до следующей ступени, шкалу норм и действие открыть сетку. Все примеры условные, цифры зависят от проверенного каталога. При досрочном завершении — «Упражнение не завершено: N из M стрел»; финальный разрядный уровень не присваивается, последний прогноз можно показать отдельно с пометкой «Разряд».

Если данные несовместимы, показывается конкретная причина и возможность исправить недостающие сведения. Для неподходящего импорта, неизвестного типа лука, другой мишени/десятки, смешанных условий или счётчика без очков числовой разряд не выдумывается. Отсутствие координат само по себе не мешает классическому сравнению, когда числовые очки и все правила упражнения известны. CG3 и PG1 не подменяют классические очки.

### Профиль, история и интерактивность

Реализовано в автономном продолжении 2 ноября: вход «Нормативы» из профиля и трофея в Прогрессе, карточки лучших полных совместимых тренировок отдельно по exerciseId/М/Ж. В профиле краткая сводка; в разделе — сумма/максимум, средний, числовой уровень, дата и название занятия, разница до следующего порога и переход к исходному отчёту. Отдельная кнопка открывает полную справочную сетку. Правка/корзина/восстановление исходного занятия обновляют производный лучший результат. Равные суммы выбирают более раннее занятие, не создают новый рекорд. Присвоенные разряды пока отдельный следующий пакет; вычисляемые результаты не объявлены присвоением.

В профиле два понятных понятия: «Присвоенный разряд» (внесён пользователем) и «Лучший результат по нормативу» (вычислен по полным совместимым упражнениям). Автоматическое повышение официального разряда от тренировки запрещено. Разные дисциплины и категории не смешиваются. Разрядная цель не создаётся; будущие общие цели приложения этим не отменяются.

В истории совместимой тренировки допустим компактный значок уровня по очкам. В статистике — динамика результата и расстояния до следующей нормы, фильтр упражнения/категории и редакции. Не создавать отменённое сравнение двух периодов. Праздничная анимация только по подтверждённому результату/личному рекорду, не по колебанию прогноза; интенсивность/выключение по существующим настройкам. Выбор места и подробности анимаций пока предложены, не утверждены пользователем.

### Данные и надёжность

Хранить каталог норм с источником/редакцией/периодом применимости и условиями; выбранное упражнение с упорядоченными ID стрел/серий, категорией и снимком условий; сведения присвоенного разряда, без разрядной цели. Производные прогнозы не записывать в базу на каждом кадре — восстанавливать из фактов. Сохранять версию алгоритма и набор фактов, на котором получен итог.

Редакция норм фиксируется для упражнения. Новые таблицы не переписывают историческое сравнение без отдельного явного действия. Для старой тренировки использовать редакцию, применимую к её дате; если её нет в каталоге, сравнение с нынешними нормами возможно только как явно выбранная справка. Не заявлять, что проверена применимость нормы на старую дату, когда известна только новая таблица.

Правка/удаление попадания пересчитывает результат и зависимые отметки. Повтор страницы/импорта не дублирует достижение; утрата основания не оставляет ложный активный рекорд. Архив сохраняет каталог/редакции, состав упражнений, категории и отметки разрядов. После восстановления расчёт воспроизводим без интернета.

### Источники и текущая степень проверки

Официальное вложение XLS получено и прочитано. [Происхождение, SHA256, строки и границы использования](references/evsk-archery-2026-source.md). Каталог сравнивает очки с конкретной редакцией; историческая применимость и все последующие поправки автоматически не подтверждаются. В интерфейсе это раскрыто. Каталог воспроизводится генератором, не переписан с пользовательской картинки.

### Порядок реализации

1. Проверить документы и составить версионируемый каталог поддерживаемых упражнений, категорий и норм; тесты точных порогов.
2. Реализовать сопоставление полного упражнения с нормами, отдельный блок итогов со шкалой среднего 0–10. Одновременно — автоматическое открытие статистики после успешного завершения.
3. Подключить живой прогноз, нормативный средний и компактную строку/всплывающий разбор без целей; не ухудшить лупу, зум и стабильность экрана.
4. Добавить сетку, присвоенный разряд профиля, лучший уровень по очкам и динамику в статистике.
5. Подключить корректные события/анимации и архив; проверить миграции/старый импорт на изолированных базах и подтверждённой копии дневника.

Границы тестов: ровно порог/на единицу ниже, M/X, пустое/неполное/полное упражнение, два раунда одного упражнения, несоответствие категории/лука/дистанции/мишени, неизвестные данные импорта, раннее завершение, редактирование после расчёта, разные редакции, возврат после перезапуска, повтор импорта/награды, отключённые анимации, архив туда-обратно. Нормы без подтверждённого источника не попадают в релизный каталог.
